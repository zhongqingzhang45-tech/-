## 1. 安装与启动

### 1.1 APK 安装

- [ ] APK 文件大小合理（预计 80–120 MB）

- [ ] 安装过程无报错

- [ ] 应用名称显示「Life」（非 AIRI）

- [ ] 点击图标后，Splash 页面显示
- [ ] Splash 页面 Logo 为 Life 品牌（心形图标）
- [ ] Splash 页面文字为「Life」或「你的 AI 伴侣」
- [ ] 首次启动耗时 ≤ 3 秒（旗舰机）/ ≤ 5 秒（中低端）
- [ ] 无白屏、无崩溃、无 ANR
- [ ] Splash → 主界面过渡流畅

### 1.3 非首次启动

- [ ] 从后台恢复正常
- [ ] 应用切换无崩溃
- [ ] 之前的对话和角色设置仍然存在

## 3. Live2D 虚拟形象

### 3.1 模型加载

- [ ] 进入聊天页后 Live2D 模型自动加载
- [ ] 加载时间 ≤ 5 秒（首次从缓存）
- [ ] 模型无错位、无模糊、无黑屏
- [ ] 模型在屏幕中的位置正确

### 3.2 动作与表情

- [ ] 角色待机动画正常播放
- [ ] 点击角色有反应（表情/动作变化）
- [ ] 文字对话时角色嘴型/表情同步
- [ ] 分辨率自适应（不同屏幕尺寸正确缩放）

### 3.3 性能（重点 ⚠️）

- [ ] 旗舰机（骁龙 8 Gen 2+）：FPS ≥ 55
- [ ] 中端机（骁龙 7 Gen 2+）：FPS ≥ 30
- [ ] 低端机（骁龙 6 系）：FPS ≥ 20
- [ ] 长时间运行（10 分钟）无明显内存泄漏
- [ ] 内存占用 ≤ 300 MB（旗舰）/ ≤ 200 MB（中低端）
- [ ] 无 WebGL context 丢失（logcat 无相关错误）

### 3.4 兼容性问题排查

如果 Live2D 加载失败，检查 logcat：
```bash
adb logcat | grep -E "WebGL|OpenGL|Cubism|Live2D|ERR"
```

常见问题：
- [ ] GPU 不支持 WebGL 2 → 应降级为 2D 静态模式
- [ ] CDN 加载失败 → 检查网络，模型是否走本地缓存
- [ ] 内存不足 → 应降级贴图分辨率

## 10. 已知限制与风险

> 这些项不阻塞发布，但需明确知晓。

### 10.1 🔴 高风险

- [ ] Android 真机 Live2D WebGL 兼容性（部分 GPU 可能不支持）
- [ ] 国内网络下 CDN 加载稳定性（Cubism SDK / 模型资源）
- [ ] 首次体验流程需完整走通（Landing → 创建 → 聊天）

### 10.2 🟡 中风险

- [ ] 语音权限在不同 ROM 上的行为差异
- [ ] 应用商店审核资料完整性
- [ ] 代码内部 AIRI 命名残留（包名/bundle ID 等，暂不影响运行）
- [ ] 国内模型 API 可用性（依赖第三方服务）

### 10.3 🟢 低风险

- [ ] 部分 i18n 翻译文案不完整（非中文用户影响）
- [ ] 桌面端 Linux `.desktop` 文件 Exec 路径已修正
