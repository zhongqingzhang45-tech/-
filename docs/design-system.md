# Design System · 设计系统

> 本文档定义 DreamLife 的视觉与交互规范。
> 任何 UI 改动必须能在本文档找到依据，否则视为越界。

---

## 1. 设计哲学

### 1.1 隐喻

> **每一个页面都是数字生命空间，不是功能列表。**

### 1.2 风格关键词

```
Anime + Future + Emotional + Digital Life
```

- 高级（Premium）
- 未来（Future）
- 沉浸（Immersive）
- 生命感（Alive）

### 1.3 反例（绝对禁止）

- ❌ 后台管理系统风格
- ❌ 廉价 AI 工具风格
- ❌ 普通白色企业后台
- ❌ 默认组件库样式直接出货
- ❌ 功能列表 / 表格堆叠

## 2. 色彩系统

### 2.1 主色

| 角色 | 名称 | 色值（参考） | 用途 |
|---|---|---|---|
| 主色 A | 星河粉紫 | `#B57EDC → #FFB6E1` | 主交互、情感高亮 |
| 主色 B | 深海青蓝 | `#4ECDC4 → #1A535C` | 冷静态、信息层 |
| 背景 | 深色空间 | `#0A0A1A → #1A1A2E` | 全局底色 |

### 2.2 情绪映射色

情绪必须能被颜色感知：

| 情绪 | 主色 |
|---|---|
| 开心 / 爱 | 星河粉紫 |
| 平静 / 思考 | 深海青蓝 |
| 害羞 | 樱粉 |
| 生气 | 暗红橙 |
| 难过 | 雾蓝紫 |
| 惊讶 | 亮青 |

### 2.3 配色规则

- 背景：深色（`#0A0A1A` ~ `#1A1A2E` 渐变）
- 卡片：毛玻璃半透明（rgba 白 5%~10%）
- 主文字：`#F0F0FA`
- 次文字：`#A0A0C0`
- 强调：主色 A 或 B
- 禁止大面积纯白背景

## 3. 组件规范

### 3.1 必备视觉特征

所有 UI 组件必须具备以下若干项：

- ✅ 大圆角（`border-radius: 16px ~ 28px`）
- ✅ Glass Morphism（`backdrop-filter: blur(20px)`）
- ✅ 微光效果（box-shadow 内发光 / 外发光）
- ✅ 渐变（背景 / 边框 / 文字）
- ✅ 柔和阴影（多层投影，非硬阴影）
- ✅ 动态效果（hover / idle 微动）

### 3.2 禁止

- ❌ 直角硬边卡片
- ❌ 单色扁平背景
- ❌ 默认 Material / Ant Design 样式
- ❌ 无过渡的硬切换

### 3.3 排版

- 标题：细体大字号 + 渐变文字
- 正文：清晰可读（最低 14px）
- 数字 / 状态：等宽字体 + 微光

## 4. 页面设计原则

### 4.1 命名

页面命名必须像「生命档案」，不是「管理后台」。

| ❌ 错误 | ✅ 正确 |
|---|---|
| 人格管理 | 生命档案 · 她的性格 |
| 记忆管理 | 生命档案 · 她的记忆 |
| 成长管理 | 生命档案 · 她的成长 |
| 设置 | 生命档案 · 她的故事 |
| 关系面板 | 生命档案 · 你和她 |
| 情绪监控 | 她此刻的心 |

### 4.2 页面结构

每个页面包含：

1. **沉浸式背景**：深色 + 微粒 / 星河 / 光斑
2. **Live2D 主体**：永远在视野中，呼吸 / 眨眼
3. **情感信息层**：以视觉化方式呈现状态（不是表格）
4. **微交互**：hover / idle / 触发的细微反馈

### 4.3 信息呈现

- ❌ 表格列表展示情绪数值
- ✅ 用粒子 / 光环 / 波形 / 渐变可视化
- ❌ 进度条直白展示「好感度 75%」
- ✅ 用关系图谱 / 距离 / 光强度暗示

---

## 5. Live2D 视觉规范

角色必须：

- ✅ 有呼吸（持续微动）
- ✅ 有眼神（跟随鼠标 / 注意力）
- ✅ 有情绪反馈（表情参数实时变化）
- ✅ 有动作（idle / 互动 / 特殊事件）

❌ 禁止：

- 静态模型截图
- 仅在用户点击时才动
- 表情与情绪状态脱节

---

## 6. 动效规范

| 场景 | 动效 |
|---|---|
| 页面进入 | 渐入 + 微缩放 |
| 卡片 hover | 微浮起 + 发光增强 |
| 情绪变化 | 颜色渐变过渡 |
| 记忆写入 | 光点扩散 |
| 关系演进 | 光环呼吸 |
| 加载 | 微粒旋转 / 流光 |

所有动效时长建议：

- 微反馈：`150 ~ 250ms`
- 状态切换：`300 ~ 500ms`
- 场景过渡：`500 ~ 800ms`

缓动函数优先：`cubic-bezier(0.4, 0, 0.2, 1)`

---

## 7. 交互原则

### 7.1 情感优先

- 交互反馈应优先传达情感，而非状态
- 例如：保存记忆成功，不是「✓ 已保存」，而是「她记住了」

### 7.2 沉浸感

- 减少「确认 / 取消 / 关闭」类冷冰冰的弹窗
- 用浮层 / 渐隐 / 自然过渡代替模态拦截

### 7.3 节制

- 信息密度低
- 留白多
- 视觉焦点单一

---

## 8. 视觉资源规范

- 图标：线性 + 微光，避免填充实心
- 插画：anime / future 风，禁止卡通 clipart
- 背景：渐变 + 粒子 + 光斑，禁止纯色

## 9. 自检清单

UI 提交前对照：

- [ ] 是否避开了「后台管理」视觉？
- [ ] 是否使用了大圆角 + 毛玻璃？
- [ ] 是否使用了星河粉紫 / 深海青蓝主色？
- [ ] 背景是否深色沉浸？
- [ ] Live2D 是否有呼吸 / 情绪反馈？
- [ ] 页面命名是否像「生命档案」？
- [ ] 是否避免了表格 / 进度条直白展示情感？
- [ ] 是否有动态效果？

任一项不通过：**禁止提交**。
