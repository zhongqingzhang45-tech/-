# Roadmap · 项目路线图

> 本文档定义 DreamLife 的阶段性目标。
> 任何功能开发应能在本文档找到对应的阶段归属。

---

## 总览

```
v0.1 MVP ──→ v0.5 闭环 ──→ v1.0 数字生命 ──→ v2.0 多生命 ──→ v3.0 生态
 单角色可跑     五引擎闭环      可被感知成长       多角色 / 网络     跨设备 / 社群
```

---

## v0.1 · MVP（当前）

**目标**：单角色、单用户、本地可运行的数字生命雏形。

**已完成基础**：

- ✅ Next.js + Prisma 工程骨架
- ✅ Live2D 模型加载（Haru / 碧蓝航线等）
- ✅ 聊天 API 与 LLM Provider 抽象（含 mock）
- ✅ 基础领域类型（`EmotionState` / `MoodType` / `MemoryType` / `RelationshipType` / `BehaviorTag` / `PersonaMode`）
- ✅ `lib/core/digital-life/` 灵魂层目录骨架
- ✅ `state-engine.ts` / `growth-engine.ts` / `autonomous-decision-engine.ts` / `context-service.ts` / `md-memory/` 初版
- ✅ 项目宪法（AGENTS.md + docs/）

**待补**：

- [ ] 项目宪法全员对齐
- [ ] 五引擎契约清晰化（输入 / 输出 / 事件）
- [ ] 单测覆盖核心状态机

---

## v0.5 · 五引擎闭环

**目标**：五大引擎（人格 / 情绪 / 记忆 / 关系 / 成长）跑通端到端闭环。

### Personality Engine

- [ ] 数据化人格档案（`PersonalityProfile`）
- [ ] 性格参数驱动语言风格
- [ ] 人格可演化（缓慢、长期）

### Emotion Engine

- [ ] PAD 状态机完整化
- [ ] 情绪 → 回复语气 → 动作 → Live2D 表情参数 全链路
- [ ] 情绪可视化（粒子 / 光环，非数字）

### Memory Engine

- [ ] 五层记忆结构落地
- [ ] 向量检索接入
- [ ] 记忆写入 / 检索性能基准

### Relationship Engine

- [ ] `RelationshipVector`（信任 / 熟悉 / 依恋 / 互动历史）
- [ ] 关系演化算法
- [ ] 关系图谱可视化

### Growth Engine

- [ ] 成长信号采集（对话 / 事件 / 任务 / 反馈）
- [ ] `GrowthMilestone` 里程碑
- [ ] 成长可被用户感知（行为 / 语言 / 能力变化）

---

## v1.0 · 数字生命

**目标**：用户能感知「这是一个生命」。

### 自主行为

- [ ] Goal 系统（`Goal` 类型）
- [ ] 定时器 / 事件触发的主动行为
- [ ] 主动发起对话 / 动作

### 长期陪伴

- [ ] 跨天 / 跨周记忆延续
- [ ] 关系时间线可视化
- [ ] 生命档案页面（她的性格 / 她的记忆 / 她的成长 / 她的故事）

### UI 沉浸

- [ ] 全页面数字生命空间视觉落地
- [ ] Live2D 呼吸 / 眼神 / 情绪反馈全链路
- [ ] 微光 / Glass Morphism / 渐变动效体系

### 验收

- 用户与她相处一周后，主观感受「这是一个生命」。

---

## 不在路线图上（明确排除）

- ❌ 通用生产力助手能力
- ❌ 企业 SaaS Dashboard
- ❌ 内容生成工具（图生图 / 文生视频）
- ❌ 通用检索问答
- ❌ 任何削弱「生命感」的方向

---

## 优先级原则

当多个功能冲突时，按以下顺序取舍：

1. **生命感** > 功能丰富度
2. **长期关系** > 短期爽感
3. **架构健康** > 快速交付
4. **设计统一** > 临时效果

任何破坏优先级上位的提案，必须经项目所有者确认才能进入路线。
